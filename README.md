# FMCG Sales Analysis

## Project Overview

This project focuses on analyzing FMCG sales data to understand sales performance and identify useful business insights.

The analysis covers revenue, cost, margin, units sold, categories, brands, cities, store formats, sales channels, and monthly sales trends.

## Tools & Technologies

- Python (Pandas)
- SQL
- Power BI
- Google Colab

## Dataset

- Records: 100,000
- Columns: 21
- Domain: FMCG Sales

The dataset contains sales and business-related information such as invoice date, city, store format, category, brand, sales channel, payment mode, units, revenue, cost, margin, stock, customer age, loyalty flag, and customer gender.

## Dataset Source

The dataset was sourced from Kaggle.

## Data Preparation

Python and Pandas were used for initial data checking and preparation.

Key steps included:

- Checking dataset structure and data types
- Checking missing values
- Reviewing basic statistics
- Handling missing customer-related values
- Preparing the dataset for further analysis

## SQL Analysis

SQL was used to analyze sales performance and extract business insights.

The analysis included:

- Revenue and cost analysis
- Margin analysis
- Category performance
- Brand performance
- City-wise revenue
- Sales channel analysis
- Monthly revenue trends
- Store format analysis

## Power BI Dashboard

A Power BI dashboard was created to visualize key sales KPIs and business trends.

The dashboard includes:

- Total Revenue
- Total Cost
- Total Margin
- Monthly Revenue Trend
- Revenue by Category
- Revenue by City
- Revenue by Channel
- Top Brands
- Interactive slicers

## Key Insights

- Fruits generated the highest revenue among the categories at approximately ₹5.0M.
- August recorded the highest monthly revenue at approximately ₹3.38M.
- Kolkata recorded the highest city-wise revenue.
- ITC was the top-performing brand by revenue.
- Omnichannel generated higher revenue than Offline sales.

This project helped analyze FMCG sales data using Python, SQL, and Power BI and convert the analysis into meaningful business insights through an interactive dashboard.
